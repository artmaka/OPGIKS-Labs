## Лабораторная работа №3

### Тема

Работа с таблицами и SQL в PyQt5.

### Описание

Программа позволяет выбрать SQLite-базу данных и выполнять несколько SQL-запросов с выводом результатов в таблицы `QTableWidget`.

В верхней части окна расположены три кнопки и выпадающий список `QComboBox`. В нижней части находится `QTabWidget` с пятью вкладками.

### Возможности программы

Через меню `Menu` доступны действия:

- `Set connection` — выбор файла базы данных через `QFileDialog`;
- `Close connection` — закрытие соединения и очистка таблиц;
- `Custom query` — открытие модального окна для выполнения произвольного SQL-запроса.

После успешного подключения на вкладке `Tab1` выполняется запрос:

```sql
SELECT * FROM sqlite_master
```

Кнопка `bt1` выполняет:

```sql
SELECT name FROM sqlite_master
```

Результат выводится в `Tab2`.

`QComboBox` содержит столбцы пользовательских таблиц базы данных. При выборе столбца результат запроса выводится в `Tab3`.

Кнопка `bt2` выводит список таблиц и SQL-команды их создания в `Tab4`.

Кнопка `bt3` выводит информацию об индексах в `Tab5`.

### Структура проекта

```text
OPGIKS-Lab3/

├── demo.db

```

`main.py` — основная программа.

`create_db.py` — создание тестовой SQLite-базы.

`demo.db` — готовая база данных для проверки работы программы.

### Тестовая база

В базе `demo.db` находятся таблицы:

- `students`;
- `subjects`.

Также создан индекс `idx_students_group`, поэтому результат кнопки `bt3` не будет пустым.

- `QFileDialog`;
- `QPushButton`;
- `QComboBox`;
- `QTabWidget`;
- `QTableWidget`;

Для работы с SQLite используется стандартный модуль Python:

```python
import sqlite3
```

### Запуск

Установить PyQt5:

```bash
pip install PyQt5
```

Если тестовой базы нет, создать её:

```bash
python create_db.py
```

Запустить программу:

```bash
python main.py
```

В меню выбрать:

```text
Menu -> Set connection
```

и открыть файл `demo.db`.

### Результат

В результате создано приложение PyQt5 для подключения к SQLite-базе данных, выполнения SQL-запросов и отображения результатов в табличном виде. Реализовано подключение и отключение базы, пять вкладок для результатов запросов, выбор столбца через `QComboBox` и дополнительное модальное окно для произвольного SQL-запроса.
