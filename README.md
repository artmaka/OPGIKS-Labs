# OPGIKS Labs

Лабораторные работы по дисциплине  
**«Основы проектирования графического интерфейса компьютерных систем»**.

## Лабораторная работа №1

### Описание

Программа представляет собой простое графическое приложение, разработанное с использованием библиотеки **PyQt5**.

В окне приложения расположены:

- область для отображения текста или изображения;
- кнопка `Default`;
- кнопка `From PC`.

При запуске программы в центре окна отображается надпись:

`Press the button for image`

<img width="654" height="504" alt="image" src="https://github.com/user-attachments/assets/9734221d-8a41-4539-a207-b9cdd440c258" />


Кнопка `Default` загружает изображение `image.png`, расположенное в папке с программой.

<img width="652" height="504" alt="image" src="https://github.com/user-attachments/assets/22f9db9b-32c3-4cbe-8578-ebb53d5c3e93" />


Кнопка `From PC` открывает окно выбора файла и позволяет загрузить изображение с компьютера.

<img width="1878" height="960" alt="image" src="https://github.com/user-attachments/assets/2c170873-8f24-452d-9fa9-76c81809b601" />


Поддерживаются следующие форматы:

- PNG
- JPG
- JPEG
- BMP

После выбора изображения текст в области отображения заменяется картинкой. Изображение автоматически масштабируется под размер области с сохранением исходных пропорций.
