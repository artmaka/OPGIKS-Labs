## Лабораторная работа №2

### Тема

Сигналы и слоты в PyQt5.

### Описание

Программа представляет собой конвертер температуры между тремя шкалами:

- Celsius (°C);
- Fahrenheit (°F);
- Kelvin (K).

Пользователь может изменить значение в любом из трёх полей. После изменения остальные два поля автоматически пересчитываются.

Например, при вводе `100 °C` программа показывает:

- `212 °F`;
- `373.15 K`.

`main.py` содержит графический интерфейс и связывает сигналы с обработчиками.

`cl2.py` содержит класс `OtherScalesConverter`, который обрабатывает изменения Fahrenheit и Kelvin и отправляет сигналы для обновления остальных полей.

### Сигналы и слоты

В программе используются стандартные сигналы компонентов PyQt5 и пользовательские сигналы.

При изменении поля `QDoubleSpinBox` генерируется сигнал `valueChanged`:

```python
self.celsius_input.valueChanged.connect(self.on_celsius_changed)
```

После этого обработчик вызывает метод класса из `cl1.py`:

```python
def on_celsius_changed(self, value):
    if not self.updating:
        self.celsius_converter.convert(value)
```

В `cl1.py` после пересчёта отправляются пользовательские сигналы:

```python
self.fahrenheit_changed.emit(fahrenheit)
self.kelvin_changed.emit(kelvin)
```

Они связаны со слотами в основном окне и обновляют значения соответствующих полей.

Аналогичным образом `cl2.py` обрабатывает изменения значений Fahrenheit и Kelvin.

### Формулы

```text
F = C × 9 / 5 + 32
K = C + 273.15
C = (F - 32) × 5 / 9
C = K - 273.15
```

### Защита от повторного вызова сигналов

При программном изменении значения `QDoubleSpinBox` снова генерируется сигнал `valueChanged`.

Чтобы избежать повторного запуска пересчётов, используется флаг:

```python
self.updating
```

Во время программного обновления остальных полей значение флага устанавливается в `True`.
